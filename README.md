## Versão 0.2.2 — preparação

O código 0.2.2 foi consolidado, mas a distribuição permanece em 0.2.1 até a publicação do instalador Windows 0.2.2 testado. As notas estão em [RELEASE-0.2.2.md](RELEASE-0.2.2.md).

A atualização é assistida: o aplicativo compara sua versão instalada com o manifesto, notifica o usuário e oferece o download do instalador. A instalação é controlada pelo usuário.
