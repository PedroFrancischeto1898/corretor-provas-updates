## Versão 0.2.2 — disponível

A versão 0.2.2 foi publicada em 27/11/2026. O instalador Windows x64 está disponível na [release v0.2.2](https://github.com/PedroFrancischeto1898/corretor-provas-updates/releases/tag/v0.2.2). O manifesto está atualizado. Consulte as [notas da versão](RELEASE-0.2.2.md).

A atualização é assistida: o aplicativo compara sua versão instalada com o manifesto, notifica o usuário e oferece o download do instalador. A instalação é controlada pelo usuário.
